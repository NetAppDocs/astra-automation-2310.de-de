= Upgrade abrufen
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
Ruft eine Upgrade-Ressource ab und stellt die gespeicherte Upgrade-Konfiguration zu Prüf- oder Managementzwecken bereit.



[[http-method-and-endpoint]]
== HTTP-Methode und Endpunkt

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/accounts/{account_id}/core/v1/upgrades/{upgrade_id}`#



[[usage-notes]]
== Nutzungshinweise

Gibt die gespeicherte Upgrade-API-Ressource im JSON-Antworttext zurück.



[[parameters]]
== Parameter

[cols="5*"]
|===
| Name | Typ | In | Erforderlich | Beschreibung 


| Konto-ID | Zeichenkette | Pfad | True  a| 
ID der übergeordneten Kontoressource

* Beispiel: {{.Account}}




| Upgrade-ID | Zeichenkette | Pfad | True  a| 
ID der aufzulistenden Upgrade-Sammlung

|===


[[response]]
== Antwort

[source]
----
Status: 200, Returns the stored Upgrade API resource in the JSON response body.
----
[cols="4*"]
|===
| Name | Typ | Erforderlich | Beschreibung 


| Typ | Zeichenkette | True  a| 
Medientyp der Ressource. Definierte Werte sind:

* "application/astra-upgrade"




| Version | Zeichenkette | True  a| 
Version der Ressource. Definierte Werte sind:

* "1,0"
* "1,1"




| id | Zeichenkette | True  a| 
Weltweit eindeutiger Bezeichner der Ressource. Definierte Werte sind:

* Entspricht dem UUIDv4-Schema




| componentName | Zeichenkette | True  a| 
JSON-Zeichenkette mit dem Namen des Softwaretyps, der aktualisiert werden kann. Definierte Werte sind:

* "acc"
* "acs"
* "Trident"
* "kubernetes"




| componentInstance | Zeichenkette | True  a| 
JSON-String, der den URI der Komponente enthält, die aktualisiert werden kann. Definierte Werte sind:

* Mindestlänge: 3
* Maximale Länge: 4095




| componentID | Zeichenkette | True  a| 
JSON-String, der einen global eindeutigen Bezeichner der Komponente enthält, die aktualisiert werden kann. Definierte Werte sind:

* Entspricht dem Astra-Identifikatorschema




| upgradeVersion | Zeichenkette | True  a| 
JSON-String, der die SemVer der Software-Image-Datei enthält, auf die ein Upgrade durchgeführt werden kann. Definierte Werte sind:

* Entspricht dem SemVer Schema




| currentVersion | Zeichenkette | True  a| 
JSON-String, der die aktuelle SemVer der zu aktualisierenden Entität enthält. Definierte Werte sind:

* Entspricht dem SemVer Schema




| Abhängigkeiten | Array[string] | True  a| 
JSON-Array von JSON-Strings, die jeweils die UUID eines Upgrades enthalten, das abgeschlossen sein muss, bevor dieses Upgrade fortgesetzt werden kann. Wird verwendet, um zu bestimmen, welche Upgrades als Voraussetzungen durchgeführt werden und in welcher Reihenfolge. Definierte Werte sind:

* Entspricht dem Astra-Identifikatorschema




| Zustand | Zeichenkette | True  a| 
JSON-String, der einen Wert enthält, der den Betriebsstatus des Upgrades angibt. Wenn Auto-Upgrade aktiviert ist, beginnen Upgrades im Status "geplant". Andernfalls beginnen Upgrades im Status "vorgeschlagen". Definierte Werte sind:

* "nicht verfügbar" - Das Upgrade ist derzeit nicht verfügbar
* "vorgeschlagen" - Das Upgrade wird vorgeschlagen, aber nicht automatisch ausgeführt, bis es genehmigt ist
* "Geplant" - Das Upgrade ist genehmigt, kann aber aufgrund von Abhängigkeiten, Zeitfenstern oder verfügbaren Ressourcen noch nicht installiert werden
* "running" - Die Aktualisierung wird durchgeführt
* "complete" - Das Upgrade ist abgeschlossen
* "fehlgeschlagen" - Das Upgrade wurde nicht abgeschlossen




| stateDesired | Zeichenkette | True  a| 
JSON-String, der einen Wert enthält, der den gewünschten Zustand für "state" angibt. Dieses Feld ist nur enthalten, wenn der Benutzer direkt eine Änderung des Zustands der Ressource anfordern kann. Definierte Werte sind:

* "vorgeschlagen" - Das Upgrade ist nicht genehmigt und darf nicht durchgeführt werden
* "geplant" - Das Upgrade ist genehmigt und muss innerhalb des angegebenen Zeitfensters durchgeführt werden
* "laufend" - Das Upgrade muss sofort durchgeführt werden, unabhängig vom Zeitfenster




| stateDetails | Array[link:#type_astra_stateDetail["type_astra_stateDetail"]] | True  a| 
Ein JSON-Array mit JSON-Objekten, das zusätzliche Details zum aktuellen „Zustand“ auflistet. Sind keine Details verfügbar, ist dieses Array leer.

* Mindestanzahl: 0




| Metadaten | link:#type_astra_metadata_update["type_astra_metadata_update"] | True  a| 
Client- und dienstspezifische Metadaten, die der Ressource zugeordnet sind. Definierte Werte sind:

* Entspricht dem Astra-Metadatenschema. Falls beim Aktualisieren nichts anderes angegeben wird, werden die Bezeichnungen, creationTimestamp und createdBy des Metadatenobjekts unverändert beibehalten.
